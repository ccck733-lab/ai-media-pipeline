# 安全审查（Safety Review）

## 目的
在内容发布前拦截合规风险：版权、广告法、平台规范、虚假信息。

## 工作流
1. 加载 `prompts/safety_checklist.md` 逐项核对。
2. 素材溯源：画面/音乐/BGM 是否授权或自制，记录来源。
3. 敏感词扫描：医疗、金融、绝对化用语、诱导外链。
4. 输出 `safety_report.md`：✅ 通过 / ⚠️ 需修改 / ❌ 禁止发布，附审查人。

## 红线（禁止发布）
- 违法、侵权、虚假、诱导私下交易、隐私泄露
- 政治/社会敏感话题规避属地法规的灰色处理

## 定位
本技能是"把关"，不替代平台审核；发布动作仍需人工或合规 API 确认。
