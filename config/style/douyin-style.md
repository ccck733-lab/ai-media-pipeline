# 风格复刻参考：抖音知识科普

> 由「风格复刻」长效技能维护。每次爆款产出后追加样本，逐步收敛账号人设。

## 人设
- 口吻：朋友式、口语、敢下判断
- 节奏：前 3 秒抛冲突/反常识，每 8-12 秒一个钩子
- 长度：60s 内讲清一个点，不铺陈

## 高频结构
1. 钩子（反常识/痛点）
2. 一个具体例子
3. 给出可操作结论
4. 互动引导（评论区留问题）

## 禁用
- 书面长句、排比堆砌、AI 腔（见 prompts/de_ai_rules.md）
- 绝对化承诺、医疗/理财硬广

## 样本库
- 把表现好的视频 transcript 贴在此处，作为后续脚本的 few-shot 参考。
